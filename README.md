# HTML 简历模板

## 项目说明

这是一个基于 `HTML + GPT` 协作整理的简约简历模板。

它的目标很直接：

- 不依赖 Word 的复杂排版
- 直接修改一个 HTML 文件就能维护简历内容
- 用浏览器即可预览，并导出为一页 A4 PDF

如果你希望简历风格保持简洁、克制、正式，这种方式会比来回调整 Word 版式更省心。

## 文件说明

- `简历_gpt.html`：简历正文与样式都在这个文件里
- `README.md`：当前这份使用说明

## 如何修改简历

打开 `简历_gpt.html` 后，按区块直接改内容即可。

### 1. 修改个人信息

定位这些内容：

```html
<title>XXXXX - 个人简历</title>
<div class="name">XXXXX-后端开发实习生</div>
<div class="contact">
  电话：XXXXX ｜ 邮箱：XXXXX
</div>
```

你可以把 `XXXXX` 替换成自己的姓名、电话、邮箱和求职方向。

### 2. 修改教育经历

定位 `教育经历` 这一段，主要改下面几类内容：

- 学校名称
- 专业名称
- 学历
- 时间
- 地点

对应结构如下：

```html
<div class="edu-school">XXXXX</div>
<div class="edu-major">人工智能｜本科</div>
<div class="edu-date">2020年09月 - 2024年06月</div>
<div class="edu-loc">郑州</div>
```

### 3. 修改荣誉奖项

定位 `荣誉奖项` 区块，按条目替换即可：

```html
<div class="award-name">XXXXX</div>
<div class="award-date">2025年11月</div>
```

### 4. 修改专业技能

定位 `专业技能` 区块，直接增删 `li` 即可：

```html
<ul>
  <li>熟悉 Java 及并发编程</li>
  <li>熟悉 MySQL 使用与优化</li>
</ul>
```

建议保留和岗位高度相关的技能，尽量避免堆砌。

### 5. 修改项目经历

定位 `项目经历` 区块，主要改三部分：

- 项目名称
- 技术栈
- 项目职责 / 项目亮点

项目经历建议按 `STAR` 法则润色后再写入：

- `S/T`：先交代项目背景、业务目标或你负责的任务
- `A`：再写你具体做了什么，使用了什么技术方案
- `R`：最后补结果、收益、优化效果或可量化价值

对应结构如下：

```html
<div class="project-title"><strong>XXXXX</strong></div>
<p class="project-sub"><strong>技术栈：</strong>Spring Boot、MyBatis、MySQL</p>
<ul>
  <li>这里写项目职责或亮点</li>
</ul>
```

如果你只是想换内容，不建议轻易改 CSS 结构；先改文本，预览没问题后再决定是否调整样式。

## 如何预览

有两种最简单的方式：

1. 直接双击 `简历_gpt.html`，用浏览器打开
2. 在浏览器里手动打开这个文件

常见浏览器都可以正常预览这份简历。

## 如何导出为 A4 PDF

推荐使用 Chrome 或 Edge：

1. 打开 `简历_gpt.html`
2. 使用浏览器打印功能
3. 目标选择“另存为 PDF”
4. 纸张选择 `A4`
5. 边距保持默认或最小
6. 先预览是否仍为一页，再导出

如果导出后出现分页问题，优先微调内容字数，不要一开始就大改样式。

## 修改建议

- 先改文本内容，再看排版效果
- 加粗只用于核心关键词，不要整段加粗
- 项目经历建议优先按 `STAR` 法则润色，再落到每条职责描述中
- 项目描述优先写结果、职责和技术亮点
- 如果目标岗位是后端开发，技能和项目内容尽量向 Java 后端方向收敛

## 适用场景

这份模板适合：

- 实习简历
- 校招简历
- 需要快速生成 PDF 版本的中文技术简历

如果你后续还想继续优化，可以在当前 HTML 基础上逐步调整内容和细节，而不必重新做一份 Word 模板。
